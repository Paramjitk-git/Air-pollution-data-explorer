# Air Pollution Data Explorer

## About

This project is a Python-based air pollution analysis and visualization application.

The program loads pollution data from a CSV file and allows users to:
- search pollution data by city
- analyze PM2.5 levels
- find the most polluted cities
- sort pollution records
- generate visualizations

## Features

- CSV data loading and cleaning
- Object-oriented programming
- Searching and filtering
- Selection sort implementation
- PM2.5 analysis
- Pollution trend visualization
- Scatter plots and bar charts
- Menu-driven command-line interface

## Technologies Used

- Python
- CSV processing
- Matplotlib
- Data analysis
- OOP

## Visualizations

- Average PM2.5 by city
- PM2.5 trends over time
- PM2.5 vs PM10 scatter plots
